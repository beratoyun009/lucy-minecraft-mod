# Lucy Restyle Minecraft mod

A Fabric mod for Minecraft 1.21.8 that lets you transform your game into any style or world you can imagine, in real time.

Powered by [Decart's Lucy Restyle model](https://platform.decart.ai/models).


## Building

```shell
./gradlew build
./gradlew runClient
```

See [Decart Cookbook](https://cookbook.decart.ai/lucy-minecraft-mod) for detailed instructions on how this mod works and how it was built.
